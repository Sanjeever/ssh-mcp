# 0.4.3

本版缩小单文件构建与 npm 包体积，继续要求 Node.js 22+。

## 变化

- 调整 Zod 导入方式，让 esbuild 裁掉未使用的导出与语言包。
- 构建保留 UTF-8 字符，减少中文工具描述与错误信息的转义开销。
- 保留现有工具、配置、主机信任、SSH/SFTP 与单包分发契约，不增加依赖。

## 升级说明

直接升级到 0.4.3，现有客户端配置无需调整。

## 验证范围

2026-10-28 在 macOS arm64、Node.js 26.11.0、pnpm 11.20.0 下通过类型检查、单文件构建、产物完整性校验，以及正常安装、禁用脚本和省略可选依赖三种隔离安装。安装验收覆盖环境文件、全部工具、标准输入、Agent、跳板机与 SFTP。

完整 70 项测试首轮通过 69 项；无 SFTP 的 Dropbear 测试在服务就绪前超时，单独重跑通过。其余测试包含独立 OpenSSH、Dropbear SFTP、官方 SDK、普通及加密私钥与强制 ChaCha20。测试使用临时密钥、信任文件及环回服务，未连接真实服务器或修改用户 known_hosts。

同机产物测量如下，npm 包均保留相同的五文件白名单与第三方许可文本：

| 产物 | 0.4.2 | 0.4.3 | 缩小 |
| --- | ---: | ---: | ---: |
| 单文件 JavaScript | 1,040,160 字节 | 675,413 字节 | 35.1% |
| npm tarball | 270,257 字节 | 205,198 字节（约 200.4 KiB） | 24.1% |

依赖版本未变化，锁文件经离线更新核对后无内容差异。最低 Node 版本、六平台原生运行和公开发布以[标签发布工作流](https://github.com/Sanjeever/ssh-mcp/actions/workflows/release.yml)为准，本机结果不替代其他平台的运行证据。
