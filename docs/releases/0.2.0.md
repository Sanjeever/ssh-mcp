# 0.2.0

本文记录本版迁移、升级影响与当时的验证结果。后续构建与依赖安装变化见 [0.2.1](0.2.1.md)，当前操作入口见[开发与发布](../development.md)。

- 将 stdio MCP 完整迁移到 strict TypeScript 与 NodeNext ESM，通过 tsc 编译 JavaScript，采用官方 MCP TypeScript SDK、ssh2 和 Zod。
- 改为单个 `@sanjeever/ssh-mcp` npm 包，命令直接运行 `dist/cli.js`。移除 Go 实现、Go 测试服务、平台子包与二进制构建机制，安装与运行无需 Go、本机 ssh/scp 或编译工具。
- 保留四工具、环境变量配置、结构化返回与错误码，以及独立连接、输出配额、取消、超时、SFTP 排他创建和下载临时文件发布语义。
- SSH 连接启用 TCP_NODELAY，消除 Linux 小包交互延迟；原生回归中的取消在目标请求阶段触发，避免把认证耗时误当作执行或传输超时。
- 支持明文、哈希、端口、IPv6、多主机、通配、否定和撤销规则。ssh2 不支持 OpenSSH 主机证书；经迁移确认，匹配 CA 规则时明确拒绝且不追加信任，不能用于依赖 CA 主机证书的连接。
- 通过 Node 环回 SSH/SFTP 服务、真实 stdio 和官方 SDK 客户端验证行为；单包正常安装、禁用安装脚本及省略可选依赖均验证实际四工具调用。
- 改造版本检查、六平台原生 CI 和 npm OIDC 发布流程。集中编译一次，同一 tarball 用于验证与发布；发布失败保留 draft，恢复时核对同版本完整性。

## 升级说明

运行要求 Node.js 22+。0.2.0 起停止发布独立 Go 二进制和六个平台子包，直接二进制用户须切换到 `npx -y @sanjeever/ssh-mcp@0.2.0` 或安装后的 `ssh-mcp` 命令。历史版本与平台包保留。已有配置格式保持一致，主机证书限制见上文。

## 验证范围

本机 macOS arm64 完成类型检查、构建、Node.js 26.11.0 与最低 22.0.0 的全套 26 项测试。两个 Node 版本的三种隔离安装路径均验证 CLI、MCP 初始化、四工具实际调用与 SFTP 往返。工作流通过 actionlint 1.7.12 静态检查；发布恢复测试使用外部边界替身，不代表真实 npm/GitHub 发布验证。

六平台原生验证和正式发布结果以 [检查与打包](https://github.com/Sanjeever/ssh-mcp/actions/workflows/ci.yml) 与 [标签发布](https://github.com/Sanjeever/ssh-mcp/actions/workflows/release.yml) 记录为准。本地验收记录不替代 Windows 原生文件发布、OIDC 和公开 registry 安装验证。

## 启动实测

以下为提交 `052e30e` 的首次本地验收记录。测量日期为 2026-10-16，环境为 macOS 26.6.2 arm64、Node.js 26.11.0、npm 11.20.0。使用 `scripts/benchmark.mjs` 串行测量，每个场景 30 次，以 MCP initialize 响应为终点，未使用 `--version` 耗时代替初始化。

| 场景 | 中位数 | P95 |
| --- | ---: | ---: |
| 0.1.1 Go 二进制直接启动 | 3.92 ms | 4.51 ms |
| 0.1.1 Node 启动器 → Go | 44.54 ms | 64.10 ms |
| 0.2.0 `node dist/cli.js` | 100.07 ms | 102.56 ms |
| 0.1.1 已发布包，预热缓存后的离线 npm exec | 193.67 ms | 205.72 ms |
| 0.2.0 本地 tarball 预装后，离线 npm exec | 229.15 ms | 241.74 ms |
| 0.2.0 本地 tarball，预热缓存后的离线 npm exec，禁用脚本 | 1611.90 ms | 2482.96 ms |

新 JS 入口启动慢于旧 Node 启动器，此次迁移简化开发和分发，未实现启动加速。旧直接入口来自迁移前本地构建及原启动器；旧缓存场景使用已发布的 0.1.1。新版预装场景在仓库外从本地 tarball 安装，测量 `npm exec --offline -- ssh-mcp`。本地 tarball 的 `--package=/绝对路径/包.tgz` 场景虽已预热，npm 仍重新处理依赖，因此单独列出；它不能代表未发布 0.2.0 在公开 registry 中的 npx 缓存命中耗时。

首次安装另作单次记录。首次本地验收包的 tarball 为 17,200 字节，解包 50,685 字节，共 11 个文件。3 项直接运行依赖固定为 MCP SDK 1.32.1、ssh2 1.17.0、Zod 4.6.7。使用本地应用 tarball、全新 npm 缓存、`--ignore-scripts --omit=optional` 安装，从 registry 获取运行依赖，耗时 18.26 秒，实际安装 100 个包（含应用），node_modules 占用约 28.10 MiB，缓存约 26.17 MiB。缓存占用包含 registry 元数据，不等于网络传输量。该记录不含应用 tarball 的公网下载，网络时间不作为 CI 门槛，也不代表公开 registry 的首次 npx 安装。
