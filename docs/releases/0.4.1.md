# 0.4.1

本版减少异步任务观察、同文件多处编辑和保存输出读取所需的调用，继续以单个 npm 包分发，要求 Node.js 22+。完整参数及边界见[使用指南](../usage.md)。

## 变化

- `ssh_task_status` 和 `ssh_output` 增加 `wait_seconds`，默认 0，最长 30 秒。状态查询可等待任务结束，输出读取可等待完整新字符或操作结束；等待到期返回当前状态，取消观察不会取消原任务。会话关闭仍清理任务与等待。
- 新增 `ssh_task_list`，列出当前会话尚未过期的任务摘要，含任务与输出句柄、服务器、状态、开始时间及可用的过期时间，不返回命令或输出正文。同时报告同步保存与异步任务共享的输出记录容量。
- `ssh_edit_file` 增加 `edits` 数组，支持基于同一个原始版本一次替换多处文本。全部匹配须唯一且互不重叠，全部校验后一次原子发布，保留权限与 uid/gid，发布前继续复查版本。最多 100 项，新旧文本合计最多 2 MiB，文件仍限制为 1 MiB。
- `ssh_output` 增加 `tail=true`，按字节预算直接读取已保存内容末尾，保留 UTF-8 边界，返回偏移可继续增量读取。容量满时，错误提示主动释放已结束输出及关联任务。

## 升级说明

原单次 `old_text`/`new_text` 编辑和默认立即返回行为保留。批量 `edits` 与顶层单次替换字段二选一；`tail=true` 与显式 `offset` 互斥。升级后重启客户端 MCP 进程，以加载新增工具及 Schema。

等待不延长原任务超时，不占远端调度配额，不连接远端，也不重试命令。输出仍每流保存前 4 MiB，尾部读取指保存区末尾；`storage_truncated=true` 时无法读取上限以外的远端输出。任务及输出仍在结束后 10 分钟过期，读取不续期。

批量编辑不承诺与外部写入者间的原子比较交换，仍要求 POSIX rename 扩展。文件类型、权限、ACL 和断电持久性边界沿用原有文本编辑与原子上传。

## 验证范围

2026-10-17 在 macOS arm64、Node.js 26.11.0、pnpm 11.20.0 下通过类型检查、单文件构建与完整 66 项测试，无跳过项。测试包含真实 stdio、官方 SDK、独立 OpenSSH 和隔离 Dropbear / BusyBox，使用临时密钥、信任文件及环回服务，未连接真实服务器或修改用户 known_hosts。

0.4.1 实际 tarball 通过完整性校验，以及正常安装、禁用脚本和省略可选依赖三种隔离安装。验收核对单包分发、CLI、全部工具、尾部输出读取、任务列表与容量、批量编辑扩展缺失、标准输入、Agent 与跳板机。批量编辑成功路径由独立 OpenSSH 和 Dropbear 测试验证。锁文件经离线更新核对，依赖未变化，未产生内容差异。

本机验证与最低 Node 版本、六平台实际原生运行及公开发布分别记录，后者以 [CI](https://github.com/Sanjeever/ssh-mcp/actions/workflows/ci.yml) 和[标签发布工作流](https://github.com/Sanjeever/ssh-mcp/actions/workflows/release.yml) 为准。
