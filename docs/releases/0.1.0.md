## 新增

- 通过 stdio MCP 提供 `ssh_list`、`ssh_exec`、`ssh_upload`、`ssh_download`，支持从客户端环境变量配置多台服务器，使用密码、已有私钥或加密私钥认证。
- 复用 OpenSSH known_hosts，支持首次连接追加信任和 strict 策略，拒绝变化或撤销的密钥，保留原文件内容、权限与符号链接入口。
- 远端命令分别返回 stdout、stderr、退出码和耗时，合计保留 128 KiB 输出并继续排空；取消和超时关闭本次连接，错误结果保留输出并说明远端状态可能不确定。
- 通过 SFTP 上传和下载单个普通文件，最大 128 MiB，默认禁止覆盖。下载完成后发布本地目标，失败保留原文件；上传失败报告可能遗留远端部分文件。
- 提供适用于 macOS、Linux、Windows 的 x64、arm64 六目标构建、薄 npm 启动器和本地安装包验证，使用者无需安装 Go、ssh 或 scp。
- 提供版本工具、中文使用与首次发布说明、MIT 许可证，以及原生测试、六目标交叉编译、标签校验、GitHub Release 和 npm OIDC 发布工作流。

## 使用说明

- `accept_new` 默认信任首次见到的主机密钥，首次连接没有外部身份核对；需要预先建立信任时使用 `strict`。
- 超时、取消或连接中断后，远端进程与文件状态可能不确定，程序不自动重试命令。
- 首次公开发布前，须初始化七个 npm 包并分别配置可信发布者。完整步骤与恢复规则见 README。工作流配置和交叉编译不能证明六个平台均已实际运行或 npm 已公开发布。
