# 0.2.1

本文记录本版单文件构建变化与当时的验证、性能数据。当前操作入口见[开发与发布](../development.md)，长期分发约束见[架构说明](../architecture.md#单包分发与发布)。

- 使用 esbuild 将应用、官方 MCP SDK、ssh2、Zod 和实际运行依赖合并为单个 ESM `dist/cli.js`，保持 Node.js 22+ 与原有四工具契约。
- 发布包不再声明 registry 运行依赖。安装只有应用包，不运行构建脚本，不下载原生加速模块；全部依赖版本在开发环境与锁文件中固定。
- 明确采用 ssh2 的 JavaScript 加密实现和内嵌 WASM，保留普通与加密私钥、AES 和 ChaCha20 能力，不降低主机验证或文件覆盖保护。
- 发布白名单固定为一个 JS、第三方许可文本、package.json、README 和 LICENSE，共五个文件。构建拒绝非 Node 内置的外部导入，自动保留实际内嵌依赖的许可。
- 模块单元测试输出到 `.build/test`，真实 stdio、SDK 客户端及隔离安装测试运行单文件发布入口。CI 继续集中构建一次，由六平台与最低 Node 22.0.0 复用同一产物，再通过 OIDC 发布。

## 验证范围

本地测试覆盖原有 SSH/SFTP 行为，新增单文件普通及加密私钥、强制 ChaCha20 与内嵌 WASM 回归。三种隔离安装核对无额外依赖，并实际调用四工具。原生与公网验证以 [CI](https://github.com/Sanjeever/ssh-mcp/actions/workflows/ci.yml) 和 [发布流程](https://github.com/Sanjeever/ssh-mcp/actions/workflows/release.yml) 记录为准。

Node.js 26.11.0 与最低 22.0.0 各通过 27 项测试。两个版本均完成正常安装、禁用脚本、忽略可选依赖三种隔离安装和实际 SSH/SFTP 调用。

## 本地性能

2026-10-16 在 macOS arm64、Node.js 26.11.0、npm 11.20.0 下串行测量。每个场景 30 次，以 MCP initialize 响应为终点；0.2.0 使用已从公开 registry 安装的包，0.2.1 使用本地单文件产物。

| 直接入口 | 中位数 | P95 |
| --- | ---: | ---: |
| 0.2.0 | 99.51 ms | 106.91 ms |
| 0.2.1 单文件构建 | 83.58 ms | 89.69 ms |

本轮初始化中位数缩短约 16%。这不代表所有机器或公网首次安装的耗时。

本地发布包压缩大小为 262,441 字节，解包为 1,030,623 字节，共五个文件。使用本地 tarball、全新 npm 缓存和 `--ignore-scripts --omit=optional` 安装，单次耗时 0.36 秒，实际安装一个包，node_modules 占用约 1 MiB。该安装不访问 registry 获取运行依赖，也不包含应用 tarball 的公网下载时间。
